## MODIFIED Requirements

### Requirement: Tiles are delivered as raw IPC byte responses, not over HTTP

Local tiles SHALL reach MapLibre through Tauri IPC only: `get_sqlite_tile` and `get_ozi_tile_projected` SHALL return `tauri::ipc::Response` (raw bytes), SHALL be registered on the plain `tauri::generate_handler!` outside the typed `specta` bindings, and SHALL be invoked from the protocol handlers through the untyped `invokeIpc` wrapper. The application SHALL NOT start a local HTTP tile server, and SHALL NOT register a tile command that no protocol handler calls.

#### Scenario: Byte commands bypass the typed bindings

- **WHEN** `src/lib/bindings.ts` is generated by the `typescript_bindings_are_up_to_date` test
- **THEN** it contains no `getSqliteTile` or `getOziTileProjected` entry, and `src/lib/api.ts` reaches those commands via `invokeIpc`

#### Scenario: No tile server dependency

- **WHEN** `grep -n 'tiny_http\|axum\|warp\|hyper\|actix' src-tauri/Cargo.toml` is run
- **THEN** it prints nothing

#### Scenario: No unprojected OZF2 tile command

- **WHEN** the registered commands are listed
- **THEN** there is no `get_ozi_tile`: OZF2 reaches the map only reprojected, through `get_ozi_tile_projected`
