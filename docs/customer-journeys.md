> Черновик от 2026-07-15; статусы сверены с кодом и пройдены на стенде 2026-09-23. Продуктовый артефакт: пути пользователя, против которых

> Источники: ADR-0020 (MVP-скоуп), docs/requirements.md, аудит 2026-07, полевые
> реалии ПСО «ЛизаАлерт». Документ на русском — целевая аудитория и владелец

**Актор всех CJ:** координатор/картограф ПСО. Нетехнический пользователь, ноутбук
(чаще Windows), в штабе или в полевом лагере, часто без интернета, всегда в спешке.

## CJ-1. Подготовка к выезду: скачать карты заранее

**Контекст:** дома/в штабе, есть интернет. Объявлен поиск — нужно увезти карты
района с собой в лес, где сети не будет.

1. Открыть приложение → список проектов с maps.lizaalert.ru
2. Найти проект поиска (по названию/дате), открыть
3. Бандл скачивается с видимым прогрессом по файлам; можно отменить и продолжить позже
4. Обрыв сети/отмена → при повторном открытии докачиваются только недостающие файлы
5. Карты открываются: Топо / Спутник / ГГЦ, переключение между ними
6. Закрыть приложение — всё лежит в кэше

- **Успех:** в лесу без сети проект открывается полным.
- **Статус:** ✅ (resume после обрыва починен в M0; datum-предупреждение для не-WGS84 добавлено)
- **Smoke:** нет — нужен (моки сети или локальный fixture-бандл)

## CJ-2. Полевой старт: открыть карты без интернета

**Контекст:** полевой лагерь, интернета нет. Ноутбук только что включили.

1. Запустить приложение → сессия восстанавливается (последний проект, карта, вид)
2. Либо: открыть кэшированный проект / локальную папку-бандл
3. Переключать карты; подписи и тайлы работают полностью офлайн
4. OSM недоступен без сети — приложение честно живёт на локальных картах

- **Успех:** от включения до рабочей карты < 1 минуты, ноль обращений к сети.
- **Статус:** ✅ — пройден на стенде 23.09.2026. Подписи треков больше не требуют
  онлайн-глифов: это DOM-маркеры с собственным раскладыванием, стиль карты глифов не
  объявляет. Офлайн-экран честен — «Нет связи — сохранённый список от {когда}», кэш
  кликабелен. Session restore разделён на две независимые части (проект и активная
  карта), так что отказ одной не уносит вторую. Открытый случай — лагерный роутер без
  аплинка: `navigator.onLine` говорит «есть», и карта всё же просит тайлы OSM
  (`docs/backlog.md`)
- **Smoke:** частично (запуск+рендер в `smoke_cj5_draw_track`); офлайн-вариант нужен —
  требует поднятой ссылки вниз и подготовленного кэша

## CJ-3. Сбор треков: слить данные с навигаторов групп

**Контекст:** группы вернулись с задач. Треки с Garmin (GPX) и старых навигаторов
(PLT, cp1251). Иногда — пачка файлов одним ZIP.

1. Импортировать GPX / PLT / ZIP-архив (диалог или drag&drop)
2. Треки появляются на карте и в списке с именем, длиной, длительностью, числом точек
3. Переименовать по ОК-стандарту (`ГГГГММДД_Позывной`) — предупреждение, не запрет
4. Задать цвет/толщину каждой группе, скрыть мусорные треки
5. Кириллические имена из PLT читаются корректно

- **Успех:** 10 треков от 5 групп загружены и различимы на карте за ~5 минут.
- **Статус:** ✅ — пройден на стенде 23.09.2026. Один диалог «Импорт…» с фильтром
  gpx/plt/wpt/zip вместо двух кнопок-близнецов, drag&drop на окно через ту же
  диспетчеризацию (`$lib/actions/import-paths`), `.wpt` читается, кириллица из PLT
  читается (cp1251 с цепочкой определения). Дроп пяти файлов со сторонним `.txt`
  отчитывается «4 из 5» и называет непрочитанный
- **Smoke:** `smoke_cj3_layer_management` покрывает слои; половина с импортом ждёт
  файлового диалога, на который умеет отвечать драйвер Mac2

## CJ-4. Разбор трека: почистить и привести в порядок

**Контекст:** трек группы грязный: GPS-шум, петли на привале, точки без времени
вперемешку, лишний хвост «от машины до старта».

1. Выбрать трек (в списке ИЛИ кликом по линии на карте)
2. Пройтись по точкам: список с lat/lon/высотой/временем, подсветка на карте
3. Удалить/переместить/вставить точки; переключаться между точками с клавиатуры
4. Отсортировать точки по времени (лечит «спутанные» треки)
5. Обрезать (crop): по видимой области карты / по диапазону времени / по выделенным точкам
6. Разрезать сегмент в точке; склеить смежные сегменты
7. Упростить (Douglas-Peucker) с живым превью и слайдером допуска
8. Каждый шаг откатывается: Cmd+Z / Cmd+Shift+Z

- **Успех:** грязный трек 5000 точек → чистый маршрут группы за ~10 минут.
- **Статус (обновлено 2026-07-15, срез 1.2):** ✅ sort по времени, crop по видимой
  области и по диапазону времени (undoable, untimed-точки сохраняются), split/join UI
  в таблице сегментов, выбор трека кликом по линии на карте, панорамирование в
  edit-режиме больше не блокируется, Cmd+Z глобально (срез 1.1). Осталось: crop по
  выделенным точкам (нужен мультивыбор — отложено), клавиатурная навигация по точкам
- **Пройден на стенде 23.09.2026.** Нашлись три вещи: упрощение из инспектора
  открывалось без чисел под ползунком, упрощение не сбрасывало кэш геометрии (карта и
  таблица сегментов продолжали показывать удалённые точки), и двенадцать команд
  редактирования не имели ответа на стенде — весь хребет CJ-4 нельзя было пройти
- **Smoke:** ядро покрыто `smoke_cj5_draw_track`; CJ-4-специфичный сценарий требует
  загруженного при старте фикстурного `.ozp`

## CJ-5. Планирование задач: нарисовать маршруты и точки

**Контекст:** штаб нарезает задачи на следующий выход. На карте — ориентиры,
место обнаружения, базовый лагерь.

1. Нарисовать трек-маршрут кликами по карте; Enter — готово, Esc — отмена
2. Поставить вейпоинты: клик по карте → имя + символ (лагерь, опасность, вода…)
3. Передвинуть/переименовать/удалить вейпоинт
4. Измерить дистанцию линейкой по карте
5. Построить круг заданного радиуса от точки (зоны поиска от ПСР)
6. Поставить точку проекцией: азимут + дистанция от выбранной точки (данные от групп по рации)

- **Успех:** 5 маршрутов + 10 точек + разметка зон за ~15 минут.
- **Статус:** ✅ — пройден на стенде 23.09.2026. Рисование, правка, измерение и
  просмотр переключаются чипами над картой (они были муляжами до 23.09); режим
  постановки точек больше не выключается после каждой — штаб ставит десять подряд;
  линейка ✅ (длина и площадь — отдельные инструменты), круг по радиусу ✅ (говорит и
  радиус, и площадь), проекция по азимуту ✅ (проверено: 40°, 350 м → точка). Потеря
  быстрых кликов при рисовании исправлена 23.09: шесть кликов с интервалом 90 мс дают
  шесть точек (до этого — примерно одну)
- **Smoke:** `smoke_cj5_draw_track` — рисование end-to-end; вейпоинты и полевые
  инструменты пока только на стенде

## CJ-6. Выдача данных: экспорт для навигаторов и OziExplorer

**Контекст:** утро, новые группы выходят на задачи. Им нужны маршруты в навигаторы
и треки для соседнего штаба с OziExplorer.

1. Экспорт трека → PLT (кириллица в cp1251, открывается в OziExplorer без моджибейка)
2. Экспорт слоя → GPX (с Garmin-цветами)
3. Экспорт вейпоинтов → WPT / GPX / PLT
4. Путь по умолчанию — `10-Tracks/` активного бандла, имя файла подставлено
5. Файл виден в Finder/проводнике одним кликом (reveal)

- **Успех:** группа получает файл, который её навигатор читает с первого раза.
- **Статус:** ✅ — пройден на стенде 23.09.2026. Track PLT ✅ (порядок полей + cp1251),
  GPX ✅, WPT ✅, экспорт точек в GPX ✅, экспорт всего дня в один GPX ✅. Каждый успешный
  экспорт называет записанный файл, показывает путь и предлагает «Показать» — до
  23.09 четыре из пяти молчали. Waypoint PLT не делается: PLT — формат треков
- **Smoke:** нет — упирается в тот же файловый диалог, что и импорт CJ-3

## CJ-7. Непрерывность: не потерять работу

**Контекст:** сквозной для всех CJ. Ноутбук в поле: батарея, случайное закрытие,
усталый оператор в 4 утра.

1. Сохранить проект: Cmd+S / видимая кнопка (не только палитра)
2. Несохранённые изменения видны (индикатор); закрытие окна с правками → предупреждение
3. Повторное открытие: recent-список, сессия восстанавливает проект+карту+вид
4. Cmd+Z/Cmd+Shift+Z работают глобально; удаление чего угодно откатывается
5. Крах/kill посреди сохранения не портит предыдущий .ozp

- **Успех:** ни один час разметки не теряется никогда.
- **Статус (обновлено 2026-07-15, срез 1.1):** ✅ атомарный save (M0), честный
  dirty-флаг в бэкенде (структурный, все классы мутаций), Cmd+S quick-save,
  Cmd+Z / Cmd+Shift+Z глобально, кнопки Save/Undo/Redo и dirty-индикатор в шелле,
  guard на закрытие окна с несохранёнными правками, переключение языка ru/en.
  Guard закрытия с 23.09 предлагает три ответа: «Сохранить и выйти», «Выйти без
  сохранения», «Отмена»; сохранение, которое не прошло, оставляет окно открытым
- **Пройден на стенде 23.09.2026:** чисто → правка → «Есть несохранённые изменения» →
  Cmd+S → «Сохранено»; закрытие с правками держит окно и спрашивает, отмена не
  закрывает, подтверждение уничтожает окно
- **Smoke:** нет — нативный guard закрытия пройти нельзя: ответ на системный диалог
  выхода завершает сессию Mac2

## CJ-8. Обмен проектами между штабами

**Контекст:** второй штаб/сменщик присылает свой `.ozp`.

1. Открыть чужой .ozp (диалог или recent)
2. Всё содержимое (слои, треки, вейпоинты, стили) на месте
3. Доимпортировать свои данные, пере-сохранить/экспортировать

- **Успех:** .ozp — надёжный контейнер обмена между версиями приложения.
- **Статус:** 🟡 — round-trip ✅; поле версии добавлено (`format_version` читается
  первым, файл от более новой сборки отклоняется с обеими версиями в сообщении, файл
  без поля читается как самый старый формат). Сам обмен между двумя штабами на стенде
  не проходился: нужны две папки бандлов и перенос файла между ними
- **Smoke:** нет — см. выше

+ smoke-тест на CJ. Решение владельца (2026-07-15): язык UI переключаемый (русский /
