# Feature Status

> Last verified against code: 2026-07-15

This table separates backend capability, UI exposure, documentation state, implementation
status, and evidence. Use it to avoid broad “supported” claims when a feature is only
partially available.

## Registered backend commands (source of truth)

The commands that exist are the ones registered in
`src-tauri/src/lib.rs::generate_handler!`. That registry is the source of
truth; this page is a description of what the application does with them.

This section used to carry the list itself, with the sentence "any command name
not on this list does not exist". It went stale the first time a command was
added and then stated, of features that had shipped, that they had no backend —
`sort_track_points` among them. A copy of a list that changes is a claim that
will be false; the registry is one command away and cannot be.

To see it:

```
grep -c 'commands::' src-tauri/src/lib.rs   # how many
grep 'commands::' src-tauri/src/lib.rs      # which
```
