# Feature Status

> Last verified against code: 2026-07-15

This table separates backend capability, UI exposure, documentation state, implementation
status, and evidence. Use it to avoid broad “supported” claims when a feature is only
partially available.

## Registered backend commands (source of truth)

The **only** IPC commands that exist are the 45 registered in
`src-tauri/src/lib.rs::generate_handler!`:

`get_app_state`, `get_tracks_geojson`, `load_projects`, `load_project`, `cancel_download`,
`open_selected_map`, `open_local_bundle`, `set_bundles_root`, `save_project`,
`load_project_file`, `import_gpx`, `import_plt`, `export_gpx`,
`get_track_export_default_path`, `undo`, `redo`, `rename_track`, `set_track_color`,
`toggle_track_visible`, `toggle_waypoint_visible`, `move_track_point`,
`delete_track_point`, `insert_track_point`, `split_segment`, `join_segments`,
`delete_track`, `add_waypoint`, `move_waypoint`, `delete_waypoint`, `rename_waypoint`,
`set_waypoint_symbol`, `simplify_track`, `set_track_line_width`, `get_track_detail`,
`get_waypoints`, `get_simplified_preview`, `reveal_bundle`, `export_track_plt`,
`export_wpt_waypoints`, `get_wpt_export_default_path`, `create_empty_track`,
`get_sqlite_tile`, `get_ozi_tile`, `get_ozi_tile_projected`, `get_ozi_metadata`.

Any command name not on this list does not exist. Earlier revisions of this table invented
commands (`sort_track_points`, `crop_to_extent`, `export_waypoints_gpx`, …) — those
features have **no backend**.
